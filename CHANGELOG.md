# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.6] - 2026-02-04

### Added
- 📚 `list-guides` tool - List all available guide documentation
- 📖 `get-guide-doc` tool - Get detailed guide documentation
- 💾 Caching mechanism for improved performance
- 🌐 Support for ES Module
- 📦 Ready for npx usage

## [0.1.0] - 2026-01-28

### Added
- 🎉 Initial release
- ✨ MCP server for ProComponents documentation query
- 📚 `list-components` tool - List all available ProComponents
- 📖 `get-component-doc` tool - Get detailed component documentation
- 💡 `get-component-example` tool - Get component code examples
- 📝 `get-changelog` tool - Get ProComponents changelog
- ℹ️ `get-pro-components-info` tool - Get ProComponents overview and version info
- 🎯 Built-in system prompts for ProComponents usage guidance
- 💾 Caching mechanism for improved performance
- 🌐 Support for ES Module
- 📦 Ready for npx usage

### Features
- Support for all ProComponents (ProTable, ProForm, ProLayout, etc.)
- Comprehensive API documentation
- Real-world code examples
- Version tracking and changelog
- Node.js >= 20.0.0 support
